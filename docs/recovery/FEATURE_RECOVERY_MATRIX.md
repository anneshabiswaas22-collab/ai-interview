## Integrated evidence batch and remaining work

The Local source is the provenance reference for the principle that model citations require deterministic checking. Its normalization deliberately ignores case/punctuation and supports ordered ellipsis fragments; it can also use a model-repaired speech transcript. Those choices are **not automatically safe** for the hosted written-practice path. The existing core prototype demands exact quotations from allowed candidate events and rejects cross-question/interviewer citations, duplicate evidence, unsupported score/observation shapes, and unknown rubric criteria.

The current recovery batch implements exact text validation from persisted written-practice events in `apps/api/src/domain/text-evidence.ts`, called by the existing `jobs/interview.jobs.ts` scorer. It preserves provider/source labels, rejects invented/cross-answer evidence, and exposes citations and uncertainty in existing report contracts and UI. Forty-two validator tests and eight new real-database integration scenarios cover its contract; the full post-change integration suite passes 165 tests. It imports neither the Python runtime nor another policy engine. Any copied expression must retain the source MIT notice; an independently written implementation should still cite this comparison and distinguish its stricter contract. Citation validation does **not** certify that a model's technical interpretation or score is correct. Adaptive policy, deterministic code execution, structured resume claims, reliable voice capture, progress analytics and whiteboard work remain explicit subsequent features, not silently retired material.
